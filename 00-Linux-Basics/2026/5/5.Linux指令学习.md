
今日指令：find 与 locate — 文件系统的“搜索引擎”

```bash
# 1. find — 实时遍历目录树，按条件精确查找
find /etc/nginx -name "*.conf"       # 查找所有Nginx配置文件
find /var/log -mtime -7              # 查找最近7天修改过的日志文件
find /root/midun -name "*.go" -exec grep -l "handleVCIssue" {} \;  # 查找包含特定函数的Go文件

# 2. locate — 查询预建索引，瞬间返回结果
locate nginx.conf                    # 秒级查找文件位置
sudo updatedb                        # 更新文件索引（locate依赖此数据库）
```

底层本质：find 是实时遍历文件系统，准确但慢；locate 是查询预构建的文件名数据库，快但不实时（新建文件需等数据库更新）。两者互补，一个是地毯式搜索，一个是索引式查询。这和你今天整理的那份文档一样——复盘就是 find，一点点回溯真实事件；知识体系就是 locate，快速定位已知信息。
