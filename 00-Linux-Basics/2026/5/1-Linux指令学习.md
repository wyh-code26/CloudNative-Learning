一、Linux 指令笔记

今日温习：echo、cat、grep、sed — 在纸上画图之前的“文本基础”

今天画图时，你描述的“输出”、“传递”，在Linux里就是靠这些命令实现的。

```bash
# 1. echo — 在终端输出文本
echo "用户 -> ZKP验证接口"   # 输出：用户 -> ZKP验证接口
echo "传递验证结果: true" > data_flow.txt  # 输出到文件

# 2. cat — 查看文件内容
cat data_flow.txt           # 查看刚才写入的数据流向描述

# 3. grep -n — 在代码中搜索概念
grep -n "handleVCIssue" main.go    # 快速找到“签发方”的角色实现

# 4. sed — 流式文本编辑器
sed -n '80,110p' main.go   # 打印第80到110行，只看签发逻辑部分
```

底层本质：echo和cat是程序世界里的“说话”和“看书”，grep是“检索”，sed是“编辑”。它们都基于 Unix 的朴素哲学：一切皆文件，一切皆文本流。你画的图是思想的流动，而 Linux 命令就是工具来捕捉和操纵这种流动。

对应之前所学：之前学了如何用 sed 批量修改代码，今天则是在用这些命令“阅读”代码。它们是你在代码世界里的眼睛和手。
