# 条件判断

## if 基本结构

```bash
if [[ "$a" -eq 1 ]]; then
  echo "a=1"
elif [[ "$a" -gt 1 ]]; then
  echo "a>1"
else
  echo "other"
fi
```

## test / [ ] / [[ ]]

| 写法 | 说明 |
|---|---|
| `test -f file` | 可移植 |
| `[ -f file ]` | POSIX，方括号两侧必须有空格 |
| `[[ -f file ]]` | Bash 扩展，支持 `&&` `||` 和正则，推荐 |

## 文件判断

| 表达式 | 含义 |
|---|---|
| `-e` | 存在 |
| `-f` | 普通文件 |
| `-d` | 目录 |
| `-r` / `-w` / `-x` | 可读 / 可写 / 可执行 |
| `-s` | 存在且非空 |
| `-L` | 符号链接 |

```bash
[[ -d "$dir" ]] && echo "目录存在"
```

## 字符串判断

| 表达式 | 含义 |
|---|---|
| `-z "$s"` | 空串 |
| `-n "$s"` | 非空串 |
| `"$a" == "$b"` | 相等（`[[ ]]` 内可用 `==`） |
| `"$a" != "$b"` | 不等 |
| `"$a" =~ regex` | 正则匹配，仅 `[[ ]]` |

## 数值判断

| 表达式 | 含义 |
|---|---|
| `-eq` / `-ne` | 等于 / 不等于 |
| `-lt` / `-le` | 小于 / 小于等于 |
| `-gt` / `-ge` | 大于 / 大于等于 |

算术比较也可以用：

```bash
(( a > b )) && echo "a>b"
```

## 逻辑组合

```bash
[[ -f "$f" && -r "$f" ]]       # 与
[[ -f "$f" || -d "$f" ]]       # 或
[[ ! -e "$f" ]]                # 非
```

## case

```bash
case "$1" in
  start)   echo "start" ;;
  stop)    echo "stop" ;;
  restart) echo "restart" ;;
  *)       echo "usage: $0 {start|stop|restart}" ;;
esac
```

## 常见坑

- `[` 两侧必须有空格：`[ -f "$f" ]`，写成 `[-f "$f"]` 会报错。
- `[[ ]]` 里变量可以不加引号，`[ ]` 里建议加。
- 数值比较不要用 `>` `<`，那是重定向；用 `-gt` `-lt` 或 `(( ))`。
