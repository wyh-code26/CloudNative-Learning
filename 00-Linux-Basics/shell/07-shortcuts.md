# Shell 常用快捷键总结

> 以下为整合版：包含原始列表和补充的常用快捷键。

## 一、光标移动

| 快捷键 | 功能 |
|---|---|
| `Ctrl + B` | 向后移动光标 |
| `Ctrl + A` | 光标移动到行首 |
| `Ctrl + E` | 光标移动到行尾 |
| `Alt + B` | 向后（左）移动一个单词 |
| `Alt + F` | 向前（右）移动一个单词 |

## 二、历史命令 / 翻页

| 快捷键 | 功能 |
|---|---|
| `Ctrl + P` | 向上翻页，相当于 `PageUp`；也可理解为上一条历史命令 |
| `Ctrl + N` | 向下翻页，相当于 `PageDown`；也可理解为下一条历史命令 |
| `Ctrl + R` | 在历史命令中反向搜索 |
| `Ctrl + G` | 退出历史搜索模式 |
| `Ctrl + S` | 正向搜索历史命令，可能被终端流控占用 |
| `Alt + .` | 插入上一条命令的最后一个参数 |

## 三、删除与编辑

| 快捷键 | 功能 |
|---|---|
| `Ctrl + H` | 删除光标前一个字符 |
| `Ctrl + D` | 删除光标所在字符 |
| `Ctrl + U` | 删除光标至行首的全部内容，不包括光标所在字符 |
| `Ctrl + K` | 删除光标至行尾的全部内容，包括光标所在字符 |
| `Ctrl + W` | 删除光标前一个单词 |
| `Alt + D` | 删除光标后面的一个单词 |
| `Ctrl + T` | 交换光标前后两个字符 |
| `Ctrl + V` | 按字面输入下一个字符 |

## 四、粘贴与撤销

| 快捷键 | 功能 |
|---|---|
| `Ctrl + Y` | 粘贴使用 `Ctrl + W`、`Ctrl + U`、`Ctrl + K` 擦除的文本 |
| `Ctrl + _` | 撤销上一次编辑操作 |

## 五、进程与屏幕控制

| 快捷键 | 功能 |
|---|---|
| `Ctrl + L` | 清屏，但保留当前正在输入的命令 |
| `Ctrl + C` | 终止当前正在运行的命令 |
| `Ctrl + Z` | 挂起当前前台进程，可用 `fg` 切回前台 |
| `Ctrl + Q` | 如果终端被 `Ctrl + S` 冻住，按它恢复屏幕输出 |

## 六、最小必记版

| 快捷键 | 功能 |
|---|---|
| `Ctrl + A` | 光标到行首 |
| `Ctrl + E` | 光标到行尾 |
| `Ctrl + U` | 删除到行首 |
| `Ctrl + K` | 删除到行尾 |
| `Ctrl + W` | 删除前一个单词 |
| `Ctrl + Y` | 粘贴被删除的文本 |
| `Ctrl + R` | 搜索历史命令 |
| `Ctrl + L` | 清屏 |
| `Ctrl + C` | 终止当前命令 |
| `Ctrl + Z` | 挂起当前进程 |
