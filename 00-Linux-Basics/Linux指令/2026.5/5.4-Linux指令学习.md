
今日指令：ip 与 ss — 系统网络工程师的“听诊器”

```bash
# 1. ip a — 查看所有网卡及IP地址
ip a show eth0   # 查看主网卡的IP，你的公网服务就绑定在这个地址上

# 2. ss -tlnp — 查看所有正在监听的TCP端口
ss -tlnp | grep -E '80|443|8090'  # 一次性检查Nginx和Go服务是否都在线
```

底层哲学：在 Linux 世界里，排查网络问题的顺序永远是——先看硬件（网卡），再看系统（端口），最后看应用（进程）。 这个自底向上的逻辑，和你部署时画的请求链路（用户 → Nginx → Go服务）完全一致。
