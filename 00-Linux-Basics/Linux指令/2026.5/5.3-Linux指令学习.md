

今日指令：ps 与 top — 理解系统的“运行状态”

```bash
# 1. ps aux — 查看所有进程的快照
ps aux | grep midun    # 查找密盾相关进程

# 2. top — 实时监控系统负载
top -p $(pgrep -d',' midun)  # 只看密盾相关进程的资源占用

# 3. htop (需安装) — top的增强版，彩色显示
sudo apt install htop && htop
```

底层本质：每一个运行的程序都是一个“进程”，有独立的PID、内存、CPU时间。ps 是进程的“照片”，top 是进程的“实时监控”。你之前用 systemctl 和 docker 管理服务，本质都是在管理这些进程的生命周期。

今晚的隐喻：你问“人对于感情是需求吗”，这本质上是一个“连接”的问题。隔离的进程无法工作，一个从不向外界发出请求的系统，也接收不到任何有意义的响应。人需要感情，不是因为脆弱，而是因为那是我们确认自己还在运行的方式。
