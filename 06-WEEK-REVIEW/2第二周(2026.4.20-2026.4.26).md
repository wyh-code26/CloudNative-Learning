# 第二周复习（2026.4.20 - 2026.4.26）

## 本周最深刻的命令/概念
`docker build -t . && docker save | gzip >`——Docker 离线镜像流转的完整链路。因为本地 Docker Hub 一直拉不下来基础镜像，只能先在能联网的云服务器上构建，再导出为 tar.gz 压缩包，下载到本地加载。这套流程让我理解了 Docker 镜像本质是一个分层文件系统打包，不是黑盒。

## 本周最值得记住的排错
1. **Alpine vs Ubuntu 的 libc 兼容性**：把自己编译好的 ZoKrates 二进制放进 alpine 容器，运行时报 `symbol not found`，因为 alpine 用 musl，ZoKrates 依赖 glibc。换成 ubuntu:22.04 基础镜像解决。这是第一次触摸到“静态链接 vs 动态链接”的真实工程影响。
2. **Nginx 443 端口配置缺失**：修复根域名时修改了 Nginx 配置，结果 zkp 子域名的 `listen 443 ssl` 被误删，导致 HTTPS 访问 404。用 `nginx -t` 检查语法通过但实际访问失败，最后用 `grep -rn "server_name" /etc/nginx/sites-enabled/` 找到被覆盖的配置文件。

## 本周需要再巩固的概念
- `proxy_pass` 和 `upstream` 的区别：什么时候用反向代理，什么时候用负载均衡池
- `docker commit` 的副作用：用 `docker commit` 手工注入 ZoKrates 后，容器的 CMD 被覆盖为 `tail -f /dev/null`，导致重启后服务不启动
